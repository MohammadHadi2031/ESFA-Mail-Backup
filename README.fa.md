# ESFA Mail Backup

فارسی · **[English](README.md)**

یک نرم‌افزار دسکتاپ ویندوزی با رابط فارسی برای تهیه بکاپ افزایشی از چند صندوق ایمیل از طریق IMAP است. برنامه برای Hetzner Mail آماده شده، اما با هر سرویس IMAP استاندارد نیز کار می‌کند. این پروژه وابستگی یا تأییدیه‌ای از شرکت Hetzner Online GmbH ندارد.

## امکانات

- رابط کاربری فارسی، راست‌چین و دسکتاپ با NiceGUI
- مدیریت چند حساب ایمیل
- بکاپ تمام پوشه‌ها، از جمله Inbox، Sent، Drafts و پوشه‌های سفارشی
- ذخیره هر پیام با فرمت استاندارد `.eml`
- خروجی گرفتن از بکاپ‌ها با فرمت `.mbox` (یک فایل برای هر پوشه ایمیل)
- دریافت افزایشی بر اساس `UIDVALIDITY` و `UIDNEXT`
- نگهداری پیام‌های قبلی حتی پس از حذف آن‌ها از سرور
- رمزنگاری رمزها با Windows DPAPI؛ رمز فقط برای همان کاربر ویندوز قابل بازیابی است
- زمان‌بندی روزانه با Windows Task Scheduler
- اجرای دستی، نمایش پیشرفت و مشاهده گزارش خطاها
- جلوگیری از اجرای هم‌زمان دو عملیات بکاپ
- بدون ارسال اطلاعات و Telemetry

## اجرای سورس در ویندوز

به Python 3.11 یا جدیدتر نیاز دارید:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

برای اجرا در مرورگر به‌جای پنجره دسکتاپ:

```powershell
python app.py --browser
```

## ساخت فایل نصب ویندوز

روش ساده، Push کردن پروژه در GitHub است. Workflow موجود در `.github/workflows/windows-installer.yml` روی ویندوز برنامه را با PyInstaller بسته‌بندی و Installer را با Inno Setup تولید می‌کند. فایل نهایی از بخش Actions قابل دانلود است.

ساخت دستی:

```powershell
python -m pip install -r requirements-dev.txt
python -m PyInstaller EsfaMailBackup.spec --noconfirm
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
```

خروجی در مسیر `Output\ESFA-Mail-Backup-Setup.exe` ساخته می‌شود.

## استفاده

1. پوشه مقصد و ساعت اجرای روزانه را در بخش تنظیمات انتخاب کنید.
2. حساب‌های ایمیل را اضافه کنید. تنظیم پیش‌فرض Hetzner معمولاً `mail.your-server.de:993` است.
3. ابتدا دکمه «آزمایش اتصال» را بزنید.
4. یک بار «شروع بکاپ» را اجرا کنید.
5. سپس «فعال‌سازی زمان‌بندی» را بزنید.

## خروجی MBOX

دکمه «خروجی MBOX» در بالای صفحه، پیام‌های `.eml` ذخیره‌شده را به فایل‌های استاندارد MBOX تبدیل می‌کند:

```text
<پوشه بکاپ>\MBOX\<آدرس ایمیل>\<نام پوشه ایمیل>.mbox
```

- برای هر پوشه ایمیل یک فایل `.mbox` ساخته می‌شود و پیام‌ها به ترتیب UID مرتب می‌شوند.
- خطوطی که در متن پیام با `From ` شروع می‌شوند طبق قرارداد mboxrd با `>` محافظت می‌شوند.
- خروجی هر بار از نو ساخته می‌شود؛ بنابراین اجرای دوباره آن بی‌خطر است و پیام تکراری ایجاد نمی‌کند.
- فایل‌های `.eml` دست‌نخورده باقی می‌مانند؛ MBOX فقط یک خروجی جانبی برای ایمپورت در Thunderbird و ابزارهای مشابه است.

## محل داده‌های برنامه

تنظیمات و گزارش‌ها در مسیر زیر ذخیره می‌شوند:

```text
%LOCALAPPDATA%\EsfaMailBackup
```

فایل‌های بکاپ فقط داخل پوشه‌ای ذخیره می‌شوند که کاربر انتخاب می‌کند. حذف برنامه، بکاپ‌ها و تنظیمات را پاک نمی‌کند.

## نکات امنیتی

- فایل `config.json` شامل رمز خام نیست.
- رمزهای ذخیره‌شده روی ویندوز با DPAPI و در محدوده حساب کاربری فعلی رمزنگاری می‌شوند.
- اتصال IMAP با TLS و اعتبارسنجی استاندارد گواهی برقرار می‌شود.
- برای نسخه سازمانی بهتر است Installer و فایل اجرایی با Code Signing Certificate امضا شوند.

## آنچه برنامه انجام می‌دهد و آنچه انجام نمی‌دهد

برای بررسی توسط واحد فناوری اطلاعات مشتری:

- تنها اتصال شبکه برنامه، IMAP over TLS به همان سرور و پورتی است که خود کاربر وارد می‌کند (`mailbackup/backup_engine.py`). هیچ آدرس دیگری در کد وجود ندارد.
- رابط کاربری روی `127.0.0.1` اجرا می‌شود و از بیرون سیستم قابل دسترسی نیست (`app.py`).
- صندوق ایمیل فقط خوانده می‌شود: پوشه‌ها با `readonly=True` باز و پیام‌ها با `BODY.PEEK[]` دریافت می‌شوند؛ بنابراین هیچ پیامی روی سرور حذف یا «خوانده‌شده» نمی‌شود.
- برنامه فقط در دو مسیر می‌نویسد: `%LOCALAPPDATA%\EsfaMailBackup` و پوشه بکاپی که کاربر انتخاب کرده است.
- نصب به‌صورت per-user و بدون دسترسی Administrator انجام می‌شود (`PrivilegesRequired=lowest`)؛ هیچ سرویس، درایور یا کامپوننت دائمی ویندوز نصب نمی‌شود.
- تنها تغییر در سطح سیستم، ساخت یک Scheduled Task با نام `ESFA Mail Backup` است که هنگام حذف برنامه پاک می‌شود (`mailbackup/scheduler.py` و `installer.iss`).
- هیچ Telemetry، گزارش‌گیری از راه دور یا به‌روزرسانی خودکاری وجود ندارد.
- کل سورس حدود ۱۲۰۰ خط پایتون است و قابل بازبینی توسط مشتری است. Installer نیز از طریق GitHub Actions ساخته می‌شود تا هر فایل اجرایی به یک کامیت مشخص قابل ردیابی باشد.
